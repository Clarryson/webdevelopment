# Web Foundations & Software Engineering Bootcamp

A complete, beginner-friendly learning roadmap and code repository covering web development from foundational HTML to petabyte-scale cloud architecture.

---

## 🗺️ 7-Day Curriculum Roadmap

Each directory contains working code, detailed specifications, and in-depth beginner guides written in clear layman's terms with real-world analogies.

| Day | Topic | Key Skills & Technologies | Directory |
| :---: | :--- | :--- | :---: |
| **Day 1** | **Web Foundations & HTML Essentials** | HTML5 structure, semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), links, lists, data tables, and interactive forms. | [`day1/`](./day1/README.md) |
| **Day 2** | **CSS Styling & Layout Fundamentals** | CSS selectors, typography, color schemes, the Box Model (Margin, Border, Padding, Content), hover states, zebra-striped tables, and cards. | [`Day2/`](./Day2/README.md) |
| **Day 3** | **JavaScript Fundamentals & Notes Toolkit** | Variables (`let`/`const`), arrays, objects, functions, array filtering (`filter`, `some`), string manipulation, and console validation testing. | [`day3/`](./day3/README.md) |
| **Day 4** | **DOM Manipulation & Scratchpad App** | Live character & word counters, dynamic warning thresholds, browser `localStorage` persistence, keyboard events (`Escape`), and dark mode CSS variables. | [`day4/`](./day4/README.md) |
| **Day 5** | **Async JavaScript, APIs & RESTful Design** | `fetch()`, `async / await`, network states (Loading, Success, Error), zero-latency client-side search, secure DOM creation, and REST API design. | [`day5/`](./day5/README.md) |
| **Day 6** | **Relational Databases & SQL Architecture** | SQLite, tables, Primary & Foreign Keys, Many-to-Many junction tables (`enrolments`), `INNER` & `LEFT JOIN` queries, indexing, and SQL vs NoSQL. | [`day6/`](./day6/README.md) |
| **Day 7** | **System Architecture & Cloud Scaling Plan** | High-scale capacity planning for "SnapShare" (10M users, 748 TB/yr), CDN edge caching, load balancing, Redis caching, read replicas, and async workers. | [`day7/`](./day7/README.md) |

---

## 🚀 How to Explore this Repository

1. **Start from Day 1** and progress sequentially through **Day 7**.
2. Each folder contains a detailed `README.md` breaking down:
   - What the code does.
   - Why it works using everyday analogies (restaurants, filing cabinets, gift boxes, and doorbells).
   - How to run and test it on your own machine.
3. All code is clean, vanilla, well-commented, and free of unnecessary complex jargon.
